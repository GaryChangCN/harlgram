## 测试过程发现的问题

- 键盘默认 OFFSET 把整页上移：已修为 RESIZE，配合 TextArea 与菜单焦点处理，在模拟器和本轮真机截图复验。
- 头像在收到下载更新后部分列表不刷新：补充渲染 key 中的可见字段，真机已复验。
- 系统深色主题与应用浅色页面不一致，导致玻璃底栏深灰：同步窗口、应用主题与 WithTheme，真机已复验。
- 设置账号页被后续 Ready 更新强制返回、连接状态固定写「已连接」、存储项仅显示说明：已修状态跳转/真实连接状态，移除无实际操作的入口。
- 图片失败重试会覆盖已有图片草稿：补与文本一致的替换确认。
- 历史空态缺少加载区分：新增 loading / loaded / hasMore / error；图片、历史、重试不可用成功构建代替服务端证据。
- 图片 Cover 挂载即移除：同根 Sheet/Cover 绑定冲突，改为 NavDestination 挂载后，真机打开、双击放大、拖动及 Back 关闭通过。
- 图片关闭按钮被顶部状态栏裁切：按窗口实际顶部避让区布局后，按钮完整显示、点击关闭且草稿保留；两指捏合仍只有几何回归证据。
- 键盘收起或冷启动后底部黑边：窗口外观移到 loadContent 后应用，并仅向底部系统安全区扩背景，本轮真机两种场景已复验。
