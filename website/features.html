现有功能

更新：2026-10-31。Harlgram 是开发中的 HarmonyOS NEXT 原生 Telegram 第三方客户端，尚未全面对齐 Telegram Web A。本页说明实际能力与边界；路线图 说明后续计划，更新日志 记录变化，逐项 Web A 对齐矩阵 提供更细的功能入口与验收条件。

如何理解状态

「已实现」是有真实协议与原生交互；「真机验证」只覆盖列出的动作和设备；「部分」表示仍有明确缺口。宿主测试、SDK 编译、设备启动与真实服务端同步分别记录，不能互相替代。当前主要验收手机单栏与阔折叠真机未展开窗口，不由单一场景推断所有编码、账户或设备均通过。

明确尚未支持

  • 服务端全局/聊天内搜索、真实云端文件夹、完整归档与资料/共享媒体。
  • 任意文件、语音/音乐完整收发，完整贴纸/GIF 交互、消息多选/反应、群/频道管理。
  • 后台推送与可靠离线通知、语音视频通话、Stories、完整隐私/设备会话管理。
  • 画中画、字幕/多音轨、质量切换及全部设备形态验收。

网络中转与通知方案仍在试验/路线图阶段；服务端实验不等于应用已具备对应能力。不要依赖当前开发预览接收重要通知。

验证基线与进一步阅读

本批次有 316 项宿主机回归、真实 SDK 26 编译签名及指定真机覆盖安装/启动记录；这些结果不等同全功能验收。详细范围见 多账户、消息展示、媒体、播放器、存储管理 和 当前状态。

公开页面只使用已审查资产与合成测试数据说明，不包含私人会话、手机号、设备序列号、部署凭据或原始截图。

Available features

Updated: 2026-10-31. Harlgram is an actively developed native third-party Telegram client for HarmonyOS NEXT. It does not yet have full Telegram Web A parity. See the roadmap, changelog, and detailed Web A parity matrix.

Reading the status

Implemented means real protocol behavior and native interactions exist. Device-verified covers only the named actions and hardware. Partial means known gaps remain. Host tests, SDK builds, device launches, and server synchronization are different evidence. Current acceptance prioritizes the single-column phone and the folded wide-fold device, not every format or device.

Not yet supported

  • Server global/in-chat search, cloud folders, full archive/profiles/shared media.
  • Arbitrary files, complete voice/music and sticker/GIF workflows, message selection/reactions, group/channel administration.
  • Background push/reliable offline alerts, calls, Stories and complete privacy/device-session management.
  • PiP, subtitles/multiple tracks, quality switching and all device forms.

Relay and notification work remain experiments/roadmap items. A server-side experiment does not imply app integration. Do not depend on the preview for important notifications.

Verification baseline

This batch has 316 host tests, a real SDK 26 signed build, and update-install/launch evidence on the designated device. These are not full-feature acceptance. Details: accounts, display, media, video, storage, status.

Public pages use reviewed assets and synthetic-test descriptions only, without private conversations, phone numbers, device serials, deployment credentials or raw screenshots.
